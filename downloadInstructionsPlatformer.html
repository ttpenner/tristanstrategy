Download Instructions

Windows download link Alpha 1

  1. Click on the link
  2. Select File -> Download as in the picture below
  3. Take note of where you download it to (probably your Downloads folder)
  4. Right Click on “Tristan Platform Alpha 1.zip and select “Extract All…”
  5. Run “Tristan Platform.exe” in the folder that gets created
  6. Click ignore if your computer flags the file
  7. Enjoy!
