Download Instructions

Windows download link Platformer installer

  1. Click on the link
  2. Select File -> Download as in the picture below
  3. Take note of where you download it to (probably your Downloads folder)
  4. Run TristanPlatformer-win-Setup.exe in the folder that gets created
  5. Click "Show More" and "Run Anyway" if your computer flags the file
  6. A desktop icon should be created so you can use it to launch the game in the future
  7. Enjoy!
